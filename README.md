# Mind Palace

This is an experiment that original designed as Human-AI (LLM Agent) co-working space, but turning into a search tool for my daily used.

## History and Credit

The first version ([FlySkyPie/simple-research-skills](https://github.com/FlySkyPie/simple-research-skills)) is extracting pipeline and prompts from [LearningCircuit/local-deep-research](https://github.com/LearningCircuit/local-deep-research) and failed eventually, so I re-designed [agent-zone-research skill](.agents/skills/agent-zone-research/SKILL.md) as Agent first approach.

The other hand, as open source user, not all FOSS Agentic CLI/IDE have great solution for search engine/web fetch, until I meet [Crush](https://github.com/charmbracelet/crush) an Agentic CLI have great built-in web search and web fetch tools, which integrated with DuckDuckGo, the skill don't work without this kind ability.
