# 卡特巴西斯（Katabasis／冥界之旅）繪畫作品研究

卡特巴西斯（Katabasis，希臘語：κατάβασις，意為「下降」）是古希臘神話與文學中的重要母題，指英雄或神祇降臨冥界的旅程[^katabasis]。本報告從西方藝術史中，系統性整理與卡特巴西斯主題相關的繪畫及雕塑作品。

## 一、奧菲斯（Orpheus）與尤麗狄絲（Eurydice）

奧菲斯下冥界试图帶回亡妻尤麗狄絲的故事，是卡特巴西斯主題中最常被描繪的題材之一[^orpheus]。

## 觀察

1. **奧菲斯**主題橫跨文藝復興至十九世紀，是西方繪畫史上最反覆出現的卡特巴西斯題材。
2. **但丁《地獄篇》**在浪漫主義時期達到視覺再現的高峰，德拉克洛瓦、布格羅、多雷等人的作品成為西方集體想像中地獄景觀的典範。
3. **基督的陰間之旅（Anastasis）**是拜占庭與中世紀基督教藝術的核心圖像，強調基督以勝利者之姿下降陰間、解放義人。
4. 古希臘瓶畫保留了最早期的卡特巴西斯視覺表現，特別是在黑繪與紅繪陶器上。
