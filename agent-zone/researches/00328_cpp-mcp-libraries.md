# C++ MCP 函式庫調查

Model Context Protocol (MCP) 是由 Anthropic 提出的開放協定，旨在標準化 LLM 應用程式與外部工具、資料來源之間的通訊方式。截至 2026 年 10 月，**Anthropic 官方尚未提供 C++ SDK**，但社群已發展出多套成熟且活躍的 C++ MCP 實作。

---

## 1. `hkr04/cpp-mcp` — 輕量級 C++ MCP SDK

- **GitHub**: https://github.com/hkr04/cpp-mcp
- **Stars**: 326 ⭐ | **Forks**: 84
- **C++ 版本**: C++17
- **授權**: MIT
- **狀態**: **活躍**（最近更新 2026 年 3 月，已收錄於 FreeBSD ports）
- **說明**: 以最小依賴與低記憶體足跡為目標的輕量級 MCP SDK，遵循 2025-03-26 協定版。
- **主要功能**:
  - JSON-RPC 2.0 通訊
  - Resource 抽象（檔案、API 等）
  - Tool 註冊與結構化參數
  - Prompt 模板
  - 多重傳輸：HTTP/SSE 與 stdio（同時支援 client 與 server）
  - 可選 SSL/TLS 支援
  - 附帶 Agent 範例（LLM tool-calling 迴圈）
- **適用場景**: 需要輕量嵌入、最少依賴的場景；也是 C++ MCP 專案中星數最高的專案。

## 2. `Neumann-Labs/mcp-cpp` — 現代 C++20 MCP SDK

- **GitHub**: https://github.com/Neumann-Labs/mcp-cpp
- **Stars**: 65 ⭐ | **Forks**: 5
- **C++ 版本**: C++20
- **授權**: Apache 2.0
- **狀態**: **活躍 — Beta**（62 次提交；wire format 已鎖定，API 在 1.0 前可能微調）
- **說明**: 目標為精確遵循協定規範的現代 C++20 SDK，追蹤協定修訂版 **2025-11-25**。
- **主要功能**:
  - 完整協定支援：Tools、Resources、Prompts、Sampling、Roots、Completion、Cancellation、Progress、Logging、Ping、Pagination
  - **Streamable HTTP** 傳輸（含 session 管理） + stdio 傳輸
  - **OAuth 2.1** 授權（HTTP 模式）
  - **Tasks**（對 `tools/call` 增加 `task` 欄位）
  - **Elicitation**（人機協作 prompt）
  - Server 主動發起 LLM 呼叫（Sampling）
  - Thread-safe 設計；future-based 非同步結果
  - 持久化筆記範例（SQLite + FTS5）
  - RAII、value semantics、`std::variant` 表達 sum type
- **適用場景**: 需要嚴格遵循最新協定、Streamable HTTP 或 OAuth 2.1 的現代應用。

## 3. `GopherSecurity/gopher-mcp` — 企業級 C++ MCP SDK

- **GitHub**: https://github.com/GopherSecurity/gopher-mcp
- **Stars**: 149 ⭐ | **Forks**: 23
- **C++ 版本**: C++14 / C++17 / C++20
- **授權**: Apache 2.0
- **狀態**: **活躍**（2,515+ 次提交；生產就緒）
- **說明**: 功能最全面的 C++ MCP 實作，以企業生產部署為目標。包含經由穩定 C API 的多語言綁定層。
- **主要功能**:
  - **5 種傳輸**：stdio、HTTP+SSE、HTTPS+SSE、WebSocket、TCP
  - 支援 MCP 協定版本 2025-06-18、2025-11-25 與 **2026-07-28**
  - **多語言綁定**（經由 C FFI 層）：Python、TypeScript、Go、Rust、Java、C#、Ruby
  - Connection pooling、circuit breaker、rate limiting、backpressure
  - Event-driven dispatcher（libevent），thread-safe
  - 可觀測性：metrics、tracing hooks、結構化日誌
  - TLS/SSL、認證中介層、請求驗證
  - Filter Chain 架構支援模組化請求處理
  - Docker 支援，Windows（Cygwin + MinGW）建置
- **適用場景**: 企業級生產部署、需多語言綁定、需多種傳輸協定支援的複雜場景。

## 4. `jesspig/modelcontextprotocol-cpp-sdk` — 雙協定世代 C++17 SDK

- **GitHub**: https://github.com/jesspig/modelcontextprotocol-cpp-sdk
- **Stars**: 2 ⭐ | **Forks**: 0
- **C++ 版本**: C++17
- **授權**: MIT
- **狀態**: **活躍**（374 次提交）
- **說明**: C++17 MCP SDK，特色為雙協定世代支援與自動版本協商。同時提供 client 與 server 函式庫。
- **主要功能**:
  - **雙世代 WireCodec**：自動在 2025-11-25（舊版）與 **2026-07-28**（現代）間協商版本
  - **完整協定**：Tools、Resources、Prompts、Elicitation、MRTR、Tasks、Subscriptions
  - **傳輸**：Stdio、Streamable HTTP、SSE、WebSocket、InMemory
  - **OAuth PKCE** + 動態 Client 註冊 (DCR)
  - **554 個測試**（含 113 個一致性測試）
  - 跨平台：Windows（MSVC、clang-cl）、Linux（GCC、Clang）、macOS（Clang）
  - `MessageFilter` pipeline 用於請求處理
  - 持久化 `FileTaskStore` 與 `FileTokenCache`
  - 文件網站：https://jesspig.github.io/modelcontextprotocol-cpp-sdk/
- **適用場景**: 需要同時相容 2025 與 2026 協定版本、或需要高度協定一致性測試的專案。

- **GitHub**: https://github.com/vparla/mcp-cpp
- **Stars**: 9 ⭐ | **Forks**: 5
- **C++ 版本**: C++20
- **授權**: MIT
- **狀態**: **活躍**（1,720 次提交）
- **說明**: 純 C++20 MCP 實作，採用 Docker-first 開發流程，專注跨平台支援與一致性測試。
- **主要功能**:
  - **傳輸**：In-memory、stdio、**shared memory**、HTTP（client/server）
  - HTTP 認證（Bearer/OAuth2 client-credentials）
  - Tools、Resources、Templates、Prompts 的分頁支援
  - Resource subscriptions（全域與 per-URI）
  - Resource templates
  - Server-side sampling handler
  - 經由 Dockerized MCP conformance server fixture 進行一致性測試
  - Docker-first 建置流程（含 Windows WSL2）
  - 實驗性 resource chunking（range reads）
- **適用場景**: 需要 shared memory 傳輸、或偏好 Docker-first 開發流程的團隊。

- **適用場景**: 已使用 Oat++ 框架的專案，希望零成本地為既有 REST API 增加 MCP 支援。

## 摘要建議

- **若追求輕量與最小依賴**：選 `hkr04/cpp-mcp`（星數最高，社群最大）
- **若追求協定完整性與現代 C++20 設計**：選 `Neumann-Labs/mcp-cpp`
- **若需企業級生產部署與多語言綁定**：選 `GopherSecurity/gopher-mcp`（功能最全面，支援 2026-07-28 協定）
- **若需同時相容 2025 與 2026 協定**：選 `jesspig/modelcontextprotocol-cpp-sdk`
- **若需 shared memory 傳輸或 Docker-first 流程**：選 `vparla/mcp-cpp`
- **若已使用 Oat++ 框架**：選 `oatpp/oatpp-mcp`

所有 C++ MCP 函式庫均為社群維護。官方 SDK 清單（TypeScript、Python、C#、Go、Rust、Ruby 為 Tier 1；Java 為 Tier 2；Swift、PHP、Kotlin 為 Tier 3）可參閱 https://modelcontextprotocol.io/docs/2026-07-28/sdk[^official-sdk]。
