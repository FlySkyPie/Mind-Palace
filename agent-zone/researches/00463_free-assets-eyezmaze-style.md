# 免費素材風格類似於 EYEZMAZE（Grow 系列）之研究報告

## 摘要

本報告旨在回答「是否有免費素材（assets）其風格類似於日本獨立遊戲網站 eyezmaze.com 的遊戲風格？」此一問題。EYEZMAZE 為日本獨立開發者 ON（On Nakayama）於 2002 年創立的網站，最著名的遊戲為「Grow」系列。其美術風格被形容為**極簡、手繪感、圓潤可愛的超現實卡通風格**，特色包括柔和溫暖的明亮色調、由基本幾何形狀構成的簡單圓潤造型，以及誇張變形的討喜角色設計[^wiki]。經過研究，確實存在多款免費、且可商用（CC0 或類似授權）的 2D 遊戲素材包，其簡潔扁平、亮色、圓潤可愛的風格與 Grow 系列相當接近。其中以 **Kenney.nl 的素材**最為貼近（特別是「Scribble」塗鴉系列與「Toon Characters」角色系列），OpenGameArt、itch.io 亦有多項 CC0 素材可供選用。

## Eyezmaze 藝術風格特徵

EYEZMAZE 的遊戲為創作者 ON（On Nakayama）一人獨力開發，程式、美術、動畫全由他完成[^wiki]。其視覺風格可歸納如下：

### 顏色
- **柔和、溫暖、愉快的色調**：顏色明亮但不刺眼、不飽和過度，營造溫和親切的氛圍。
- **依主題調整色系**：如《GROW Valley》採用大地色系反映自然景觀，《GROW Cube》採用宇宙色系配合其太空主題[^grok]。
- 當遊戲元素「升級」時，色彩會戲劇性地變化，例如一坨土塊進化成綠意盎然的土地、藍色水面、盛開的樹木與繽紛角色[^rps]。

### 造型與圖形
- **圓潤的簡潔 2D 造型**：角色與物件由基本幾何形狀構成（圓形、圓角矩形、柔和的自然有機形狀），沒有尖銳、粗糙或寫實的幾何[^flashvault]。
- **「精簡而極簡」**：畫面只包含必要的遊戲場景與一排可點擊的圖示，沒有 UI 雜訊[^wiki]。
- **抽象符號圖示**：早期 Grow 遊戲中玩家點擊的按鈕是抽象或半抽象的符號，而非寫實描繪[^wiki]。

### 角色設計
- **超可愛、簡化的生物**：遊戲中反覆出現由圓滿身軀、細小四肢與豐富表情構成的討喜生物（如 Tonties、Onkies）[^wiki][^flashvault]。
- **非寫實的人體比例**：角色被誇張化、簡化並可愛地變形（大頭、小身體、極簡五官）[^grok]。
- 部分生物跨遊戲反覆出現，形成吉祥物式的共享宇宙[^wiki]。

### 動畫
- **流暢的階層式 2D 動畫**：每次點擊觸發「成長序列」，元素會轉化、移動並互動[^mdecapua]。
- **變化與進化動畫為核心獎勵**：看一個小東西成長為複雜且有生命的東西（化石變成生物、種子變成樹、水窪變成河流）是主要視覺樂趣[^mdecapua]。
- 錯的順序也常產生有趣、幽默或怪異的動畫，讓玩家保持投入[^mdecapua]。

### 整體評估
EYEZMAZE 的風格是**日本 kawaii 極簡主義、超現實的轉化動畫，與克制、無文字視覺敘事**的結合，拒絕複雜與寫實，擁抱魅力與情感溫暖。其創作哲學是「做出全世界人人都能享受的作品」，無需文字即可跨文化理解[^rps]。

> 重要澄清：Grow 系列後期的 HTML5 版本使用了**精緻的向量圖形（vector graphics）**，早期 Flash 版本則為低解析度像素風（pixel-style）圖片。因此「最貼近 Eyezmaze 風格」的免費素材更偏向**扁平向量／平塗色塊**，而非高精細像素藝術[^flashvault]。

## 總結與建議

**結論為「是」**：確實存在免費且通常可商用（以 CC0 為主）的素材，其風格與 eyezmaze.com 的 Grow 系列相近。最推薦的起點依序為：

1. **Kenney.nl**（https://kenney.nl/assets）— 大量 CC0 扁平卡通／向量素材，尤以 **Scribble**（塗鴉手繪）、**Toon Characters**（卡通角色）、**Abstract Platformer**（抽象極簡）系列最貼近 Grow 風格。數萬個素材跨越 200+ 套件，所有套件可無縫混搭[^kenney2d]。
2. **OpenGameArt**（https://opengameart.org）— 若需要可縮放的真向量（SVG）或模組化動畫角色，此處有高品質 CC0 選項[^oga_modular][^oga_bird]。
3. **itch.io 免費素材頁籤**（tag: cute / 2d / vector / cc0）— 有大量獨立創作者的扁平向量與可愛卡通素材，但**務必逐套檢查授權**，因部分僅限非商業用途[^itch_cute][^itch_vector]。

### 選用注意事項

- **授權核對**：所有素材使用前務必核對個別授權條款。CC0 最自由（不需署名可商用）；CC BY 需署名；部分 itch.io 套件僅限非商業用途（免費版），付費版才可商用[^cupnooble][^shubibubi]。
- **像素 vs 向量**：Eyezmaze 近代遊戲以**扁平向量圖**為主。若要精準重現此風格，優先選擇向量（SVG）或扁平塗鴉素材；像素風素材雖也可用，但風格貼近度略低。
- **手繪感**：Grow 系列帶有手繪塗鴉感，**Kenney Scribble 系列**在「手繪／插畫」感覺上最為接近[^kenney_scribble]。
