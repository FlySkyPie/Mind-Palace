# Project PLATEAU：日本 3D 都市模型專案的背景與歷史

## 概述

Project PLATEAU（プラトー）是由 **日本國土交通省（MLIT）** 主導的國家級專案，旨在推動日本全國 3D 都市模型的整備、應用與開放資料化。其名稱源自法國哲學家吉爾·德勒茲與精神分析家費利克斯·伽塔利的著作《千高原》（Mille Plateaux），基於「多樣且自律分散的系統透過平面式連接與連續，從而獲得韌性」的哲學。國土交通省期待 3D 都市模型能為社會提供無數的連結節點，讓所有領域透過網路空間相互連結並發展，因而採用此名稱[^name]。

## 背景：1995 年至 2019 年的前史

PLATEAU 的根基源於日本長期以來 **地理空間資訊（GIS）應用** 的發展脈絡[^mlit_about]。

| 年份 | 事件 |
|---|---|
| 1995.1 | **阪神淡路大地震** — GIS 於防災中獲得應用，但各相關部省各自建置系統 |
| 1995.9 | 地理資訊系統（GIS）相關省廳聯絡會議成立 |
| 1996 | 制定國土空間基礎資料整備及 GIS 普及促進長期計畫 |
| 2000 | 制定都市計畫 GIS 標準化指引 |
| 2007 | 制定地理空間資訊活用推進基本法 |
| 2016 | 制定第 5 期科學技術基本計畫／G 空間資訊中心啟動 |
| 2019 | 都市計畫基礎資訊開放化 |

1995 年的阪神淡路大地震讓 GIS 的重要性受到重視，但各省廳各自建置系統的結果，導致資料的相互運作性存在課題。2007 年的地理空間資訊活用推進基本法與 2016 年 G 空間資訊中心的啟用，推動了地理空間資訊的基礎建設，而 2019 年的都市計畫基礎資訊開放化，則成為 PLATEAU 誕生的直接前奏[^mlit_about]。

## 專案啟動（2020 年）

2020 年，國土交通省設立「城鄉發展數位轉型實現會議」，並制定行動計畫「城鄉發展數位轉型實現願景」。**Project PLATEAU** 正式作為此願景的數位基礎設施啟動[^mlit_dx][^plateau_about]。

### 主導組織

- **主導**：國土交通省（MLIT）都市局
- **營運夥伴**：一般社團法人 UDC Initiative、INA 新建築研究所、株式会社 I-Transport Lab.、Accenture 等
- **公私協力**：「3D 都市模型的整備與應用推廣檢討分科會」— 96 個自治體團體 + 112 家民間企業，約 200 個團體參與
- **社群**：超過 400 個組織參與 PLATEAU 社群[^plateau_partners]

專案合作夥伴涵蓋超過 100 個組織（包括 Accenture、NEC、NTT docomo、鹿島建設、竹中工務店、三菱綜合研究所、Unity、ESRI Japan、ZENRIN 等）[^plateau_partners]。

## 目標與願景

### 整體願景

定位為國土交通省與各方參與者合作推動的日本全國城市數位孿生實現專案[^plateau_vision]。

### 三大提供價值

1. **可視化（視認性）** — 立體化認識城市空間，提升說明力與說服力
2. **模擬（再現性）** — 在網路空間上實現廣泛且精密的模擬
3. **互動（雙向性）** — 提供實體空間與網路空間相互資訊交換的平台[^plateau_vision]

### PLATEAU 願景 2026（最新）三大重點

1. **資料整備與更新的效率化**
2. **服務實作的進一步推進**
3. **向國外推展城市數位孿生**[^plateau_vision_2026]

### 核心目標：建構生態系統

目標是透過建構 3D 都市模型整備、應用與開放資料化的生態系統，推動城鄉發展的數位轉型[^plateau_vision]。

## 重要里程碑

| 年份 | 里程碑 |
|---|---|
| **2020** | **Project PLATEAU 啟動**。制定城鄉發展 DX 實現願景。開始開發首批應用案例 |
| **2021** | **全國 56 個城市的 3D 都市模型整備與開放資料化**。發布 PLATEAU VIEW。制定標準產品規格書 v1.0。官方網站上線 |
| **2022** | **PLATEAU 標準 2.0 普及與 3.0 開發**。確立資料更新機制。擴展至全國約 100 個城市。制定 PLATEAU 願景 2023 |
| **2023** | 開始檢討導入 OGC CityGML **3.0**。持續擴展標準規格。透過補助制度加速地方城市的資料整備 |

| **2025** | 於巴塞隆納 Smart City Expo World Congress（SCEWC 2025）參展。擴展至約 300 個城市 |

| **2028-2030（目標）** | 根據應用案例需求擴展 PLATEAU 標準。確立短週期資料更新。進一步擴大資料整備範圍與社會實裝 |

## 資料覆蓋範圍的擴大

| 時期 | 城市數 |
|---|---|
| 2021 年度 | 56 個城市（首年） |
| 2022 年度 | 約 100 個城市 |
| 2024 年 | 250+ 個城市 |
| 2026 年 5 月 | **306 個地點** |
| 2024-2027 目標 | 約 500 個城市 |

資料可從 **G 空間資訊中心**（由一般社團法人社會基盤資訊流通推進協議會（AIGID）營運）免費下載，並允許商業使用[^plateau_open_data]。

## 採用技術標準

### 核心標準：CityGML

PLATEAU 的 3D 都市模型以 **OGC（Open Geospatial Consortium）的國際標準 CityGML** 為基礎[^plateau_citygml]。

- **基礎版本**：OGC CityGML 2.0（日本本地化版本）
- **檢討中**：OGC CityGML 3.0（2023 年起開始檢討導入，2026 年制定標準產品規格書草案）

### PLATEAU 標準規格書

國土交通省制定的「**3D 都市模型標準產品規格書**」規範了資料格式、品質、命名規則、分割方法等。

- **最新版**：Version 5.0（2026 年 3 月）
- **初版**：2021 年 3 月制定（日本首個 3D 都市模型標準資料模型）

### LOD（細節層級）

CityGML 定義了五個層級的 LOD，PLATEAU 主要支援 **LOD1（區塊模型）至 LOD2（含屋頂形狀模型）**。LOD3 以上的擴展亦在檢討中[^plateau_citygml]。

### 發布資料格式

| 格式 | 用途 |
|---|---|
| **CityGML**（XML 基礎） | **標準資料格式** |
| **3D Tiles** | WebGIS 高速顯示（CesiumJS 等） |
| **MVT**（Mapbox Vector Tile） | WebGIS |
| **GeoJSON / FGDB**（File Geodatabase） | GIS 軟體串接 |
| **FBX / OBJ** | 3D 軟體串接 |
| **GeoTIFF** | 正射影像與地形紋理 |

### 空間參考系統

- **EPSG:6697**（日本測地系 2011 經緯度座標系 + 東京灣平均海面高程）— 主要
- **EPSG:6668**（日本測地系 2011 經緯度座標系）— 不需高程的資料使用[^plateau_citygml]

### 網格分割

依據標準地域網格（統計局），以 **3 次網格（約 1 公里）** 或 **2 次網格（約 10 公里）** 為單位進行檔案分割[^plateau_citygml]。

### 關於 IndoorGML

官方資料中未發現明確提及 IndoorGML 的敘述。不過，存在運用地下街資料的導航系統應用案例（東京都澀谷區／北海道札幌市／香川縣高松市）等與室內空間相關的計畫，可能透過 BIM 模型或 CityGML 的室內擴展間接相關[^plateau_usecase]。

## 開源軟體與 SDK

GitHub Organization「Project-PLATEAU」已公開超過 120 個儲存庫[^github_plateau]。

主要工具：
- **PLATEAU SDK for Unity** — 對應 Unity 遊戲引擎
- **PLATEAU SDK for Unreal Engine** — 對應 Unreal Engine
- **PLATEAU VIEW（4.0/5.0）** — 瀏覽器基礎的 3D 都市模型檢視器
- **PLATEAU GIS Converter** — CityGML 轉換為 GIS 格式的工具（Rust 開發）
- **火災延燒模擬器**、**流體分析模擬器**、**都市結構分析工具**等

## 應用案例

官方網站刊載了 **148 件** 案例（截至 2026 年）[^plateau_usecase]。

### 主要領域

| 領域 | 具體案例 |
|---|---|
| **都市計畫與城鄉發展** | 景觀模擬、開發許可 DX、XR 市民參與型城鄉發展 |
| **防災與減災** | 洪水模擬、火災延燒模擬、建築物振動分析、海嘯浸水預測 |
| **觀光與地方創生** | XR 觀光內容、元宇宙空間、Fortnite 城市行銷 |
| **移動與機器人** | 飛行汽車起降場規劃支援、無人機模擬、自動駕駛地圖 |
| **環境與能源** | 太陽能發電模擬、熱島效應分析、熱環境模擬 |
| **基礎設施管理** | 地下埋設物導航、點雲整合、BIM 串接 |
| **不動產** | 不動產鑑價與固定資產稅評估應用、景觀模擬 |

### 特色案例

- **飛行汽車起降場規劃支援 Web 應用**（榮獲大獎）
- **地下街導航系統**（澀谷、札幌、高松）
- **Fortnite × 3D 都市模型**城市行銷（埼玉市）
- **衛星資料城市數位孿生**（與馬來西亞的國際合作）
- **AI 環境模擬**（兵庫縣朝來市）— 洪水模擬高速化

## 國際推展

PLATEAU 願景 2026 將「向國外推展城市數位孿生」定位為三大支柱之一[^plateau_vision_2026]。

- **SCEWC 2025（巴塞隆納）** 參展 — 27,000 人與會，367 人參觀 PLATEAU 展位。獲得西班牙、義大利、法國、沙烏地阿拉伯等國的關注
- **馬來西亞實證**：運用衛星資料建構城市數位孿生調查（蘭戈爾州 Semenyih 與福岡縣久留米市合作）
- **運用技術平台「Re:Earth」**（Eukarya 公司）推動海外推展[^plateau_scewc]

## 與各國數位孿生專案的比較

| 項目 | 日本（PLATEAU） | 新加坡（Virtual Singapore） | 歐盟（Destination Earth） |
|---|---|---|---|
| **啟動年份** | 2020 年 | 2014 年 | 2022 年 |
| **主導機關** | 國土交通省 | 國家研究基金會（NRF） | 歐盟執委會 + ESA 等 |
| **標準格式** | **CityGML**（OGC 國際標準） | 部分 CityGML | 自訂格式與 CityGML 混合 |
| **資料公開** | **開放資料**（免費、可商用） | 部分限制 | 部分免費／研究目的 |
| **覆蓋範圍** | **306 個城市**（2026 年） | 新加坡全境（1 個城市） | 各國主要城市 |
| **SDK 提供** | Unity, Unreal, Web（開源） | 有限 | 部分研究機構提供 |
| **社群規模** | 400+ 組織與自治體 | 政府主導 | 歐盟成員國主導 |

PLATEAU 的優勢特點包括：(1) **開放資料 × 開源軟體**實現自由使用與修改、(2) 透過補助制度 **快速擴展**（5 年從 56 個城市擴展至 306 個城市）、(3) 透過「挖掘」與「再利用」既有測量成果與 GIS 資料實現 **高成本效益的資料整備**、(4) 遵循 **CityGML 國際標準**確保相互運作性、(5) 追求資料整備、應用與開放資料化自主發展的 **生態系統導向**、(6) 針對地震、海嘯、洪水等日本災害特性，充實 **以防災為核心** 的應用案例。

## 結論

Project PLATEAU 自 2020 年啟動以來，僅 6 年便成長為覆蓋 306 個城市的世界頂尖城市數位孿生專案。遵循 CityGML 國際標準的開放資料策略、透過補助制度促進全國自治體參與、提供開源 SDK 群形成生態系統，以及累積防災、都市規劃、移動等多元應用案例，共同支撐了其快速成長。截至 2026 年，PLATEAU 已進入向外推展的階段，將日本的城市數位孿生模式推向國際。
