# Tile Map Zoom 層級：何時 1px ≈ 1m？

## 問題

在標準 Web Mercator 投影的 Slippy Map 中，每個 zoom 層級對應一個地面解析度（meters per pixel）。問題是：**在哪個 zoom 層級時，地圖上 1 個像素約等於現實世界中 1 公尺？**

## 公式

標準 256px 瓦片地圖中，赤道上的每像素地面距離計算公式為[^zoom-levels]：

```
S_pixel = C / 2^(zoom + 8)
```

其中：
- `C` = 赤道周長 = 40,075,016.686 m（WGS84 參考橢球體）
- `zoom` = 縮放層級（整數，0 起算）
- **256 px 瓦片**：分母為 `2^(zoom + 8)`（因為 256 = 2^8）

若緯度不為 0，需乘上 `cos(latitude)`：

```
S_pixel = C × cos(latitude) / 2^(zoom + 8)
```

## 計算結果（赤道）

| Zoom | m/pixel（赤道） | 說明 |
|------|----------------|------|
| 16   | 2.389          | 每像素 ~2.4 m |
| **17** | **1.194**    | 每像素 ~1.2 m — **最接近 1 m 的整數 zoom** |
| 18   | 0.597          | 每像素 ~0.6 m |
| 19   | 0.299          | 每像素 ~0.3 m |

資料來源[^zoom-levels]。

若要 **1 px = 1 m 精確值**，解方程：

```
40,075,016.686 / 2^(zoom + 8) = 1
zoom + 8 = log₂(40,075,016.686) ≈ 25.256
zoom ≈ 17.256
```

## 緯度影響

由於 Web Mercator 投影在垂直方向有拉伸，實際地面解析度隨緯度變化：

| 緯度 | cos(lat) | zoom 17 實際 m/px | 1px≈1m 的 zoom 值 |
|------|----------|-------------------|-------------------|
| 0°   | 1.000    | 1.194             | **17.256** |
| 30°  | 0.866    | 1.034             | 17.118     |
| 45°  | 0.707    | 0.844             | 16.907     |
| 60°  | 0.500    | 0.597             | 16.256     |

所以在 **台灣（約北緯 25°）**，cos(25°) ≈ 0.906，zoom 17 的實際解析度約為 **1.082 m/px**，更加接近 1 m。

## 結論

- **整數 zoom 層級**：**zoom 17** 是「1 pixel ≈ 1 meter」的最佳近似，赤道上約 1.194 m/px，中低緯度更接近 1 m/px。
- **精確值**（赤道）：zoom ≈ **17.256** 時 1 px = 1 m，但非標準整數層級。
- **256px 瓦片 vs 512px 瓦片**：若使用 512px 瓦片（如 Mapbox Vector Tiles），公式中分母改為 `2^(zoom + 9)`，則 zoom 18 才對應 1.194 m/px，zoom 16 則對應 2.389 m/px[^zoom-levels]。
